# ECE241

A collection of digital logic design labs covering fundamental hardware components and sequential logic.

## Labs

- **Lab 1: Switches, Lights, and Multiplexers** — Digital inputs/outputs and multiplexing
- **Lab 2: Numbers and Displays** — Number representation and display logic
- **Lab 3: Latches, Flip-Flops, and Registers** — Sequential logic and storage elements
- **Lab 4: Counters** — Counter design and sequential circuits
- **Lab 5: Finite State Machines** — FSM design and implementation

## Topics Covered

- Combinational logic
- Multiplexers
- Digital displays
- Latches and flip-flops
- Registers
- Counters
- Finite State Machines (FSMs)
